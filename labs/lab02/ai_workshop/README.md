# Warsztat: AI w pracy inżyniera oprogramowania

Mały projekt do Lab 02 (część B). Pracujesz **w kopii tego folderu** w `submissions/<login>/lab02/ai_workshop/`.

## Co będziesz robić
Użyjesz Microsoft 365 Copilot Chat (konto uczelniane, patrz Lab 01) do: analizy kodu, poprawiania błędów, pisania testów, refaktoryzacji i dokumentowania rozwiązania.

## Uruchomienie
```bash
cd submissions/<login>/lab02/ai_workshop
python -m pytest            # jeden test nie przechodzi – to część zadania 2
```

## Pliki
- `task.md` – instrukcja,
- `bad_example.py` – kod z błędem,
- `risk_score.py` – funkcja do testów,
- `analyze_heart_data.py` – skrypt analizy (dane lokalne z `data/churn.csv`),
- `tests/` – testy,
- `docs/prompts.md` – przykładowe prompty.
